# 对话界面布局与按钮录音调整汇总（2026-07-28）

## 1. 本轮目标

本轮工作围绕 VR 对话界面的可读性、中心视野避让和录音交互收敛展开：

- 对话相关面板放置在视野四周，避免遮挡中心场景。
- 放大任务目标内容，并将任务面板移到主画布左侧的独立世界空间画布。
- 任务画布持续面朝用户，并保持与全局界面缩放一致。
- 移除“空指向扳机按住录音、松开结束”的硬件录音入口。
- 录音、结束和重试只通过界面按钮进入现有状态机。
- 同步中英文使用说明、技术文档、场景资源和自动化测试。

## 2. 录音交互调整

### 2.1 最终交互规则

- `Listen / End / Retry` 负责需求录音。
- `Speak / End` 负责对话录音。
- PICO/OpenXR 扳机仅在射线命中 UI 按钮时确认点击。
- 扳机未指向按钮时，按下或松开都不会改变录音状态。
- `A / X` 仅确认当前射线指向的 UI 按钮；没有目标时不触发操作。
- 退出和世界画布重居中快捷方式保持不变。

### 2.2 代码实现

- `SceneTalkOrchestrator` 删除控制器专用的录音开始、结束和可用性入口，按钮继续调用现有录音状态机，不另建并行状态。
- `SceneTalkInteractionBootstrap` 删除扳机录音所有权、空指向开始录音和松开结束录音逻辑。
- 扳机与 `A / X` 仍可确认射线指向的按钮，但不能绕过 UI 直接开始、结束、确认或重试。
- 请求状态提示改为“点击录音开始录制”，不再提示扳机录音。
- `DialogueRecoveryTests` 增加反射断言，保证控制器录音 API 不会被意外恢复；原有按钮防连击、LLM 失败恢复和 Avatar 播放失败重试覆盖保留。

## 3. 对话面板布局

- 对话面板继续保持底部全宽布局，宽度为 `840`。
- 正常显示时中心位置调整为 `Y=-170`，高度调整为 `180`。
- 隐藏字幕时中心位置为 `Y=-200`，高度为 `120`。
- 用户字幕、Avatar 字幕、纠错反馈、状态文字和发言按钮只调整偏移量与可用空间，不改变原有交互结构。
- PlayMode 布局断言要求对话面板保持在主画布内部、处于底部区域并避开中心画面。

## 4. 独立任务画布

### 4.1 结构与位置

- 运行时创建独立世界空间画布 `SceneTalkVR Task Goal UI`。
- 该画布是主世界画布的子节点，因此会跟随主画布重居中和整体缩放。
- 相对主画布偏移为 `(-560, 100)`，任务面板在子画布内居中。
- 面板尺寸为 `300 × 320`，标题字号为 `26`，目标文字基础字号为 `20`。
- 子画布使用独立排序，并继承主画布相机、排序层、附加 Shader Channel 和动态 PPU。

### 4.2 朝向与缩放

- 任务画布不使用固定旋转角度，而是根据交互相机与画布位置动态计算水平朝向。
- 创建、用户设置变更和每帧后处理都会刷新朝向，因此界面缩放或头显位置变化后仍面向用户。
- 变换链为：场景父级 `(1,1,1)`、主画布统一缩放、任务画布本地缩放 `(1,1,1)`，不存在 X/Y 非等比缩放或旋转叠加造成的剪切畸变。
- 支持的界面缩放范围及理论尺寸如下：

| 界面缩放 | 世界缩放 | 任务面板物理尺寸 | 约占视角 |
| --- | --- | --- | --- |
| 50% | 0.0025 | 0.75 × 0.80 m | 19.9° × 21.2° |
| 100% | 0.0050 | 1.50 × 1.60 m | 25.9° × 27.6° |
| 125% | 0.00625 | 1.875 × 2.00 m | 27.1° × 28.8° |

任务画布保持竖直，只进行水平转向；由垂直位置产生的最大理论观察夹角约为 `8.5°`，对应的透视压缩低于约 `1.1%`，不属于布局畸变。

### 4.3 测试约束

编辑器采集流程和 Pilot 采集流程的 PlayMode 测试均增加以下断言：

- 任务目标使用独立 Canvas。
- 子画布跟随主世界画布。
- 任务面板完整位于主画布左侧。
- 任务面积和目标文字字号不低于可读性要求。
- 子画布使用交互相机并面向用户。
- 对话面板继续位于底部安全区。

## 5. 场景、字体与协议资源

- `SampleScene.unity` 保存了相机视场角 `77.5°`、录音按钮防连击时间 `0.35s` 以及中文 TMP 文本的 Unity Unicode 序列化结果。
- `NotoSansSC-VF SDF` 保持动态字体模式、源字体引用、`2048 × 2048` 动态图集上限和多图集支持；落盘的空白动态缓存由 `2048 × 2048` 清理为 `1 × 1`，运行时仍按需生成中文字符，不改变 UI 几何缩放。
- 实验协议确认值没有改变，仅同步了 Unity 保存后的确认时间。
- `ExperimentBuildInfo` 同步了本地编辑器采集快照信息。
